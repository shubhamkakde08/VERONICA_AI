Put company master files here (Excel .xlsx or .csv, first row = column headers):
  item master, customer list, plant / godown codes, grade list ...
VERONICA reads them directly - no ERP query - and re-reads a file as soon as you save it.
Everyone signed in can use files in this folder. Files in the "private" sub-folder are for admins only.
Keep one sheet per file (only the first sheet is read).
