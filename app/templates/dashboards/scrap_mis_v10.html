How to export files from ERP

  1. Open ERP & go to 06.400.00 – Special Engines – Production Planning and untick Dashboard Engine.
  2. Click on Production Summary & find R959 Production Summary Report-Welded.
  3. Select the period, export as CSV and name the file Welded.
  4. Find R960 Production Summary Report-Seamless in the same Engine.
  5. Select the period, export as CSV and name the file Seamless.
  6. Go to Slitting Plan Report on the same path 06.400.00 – Special Engines – Production Planning.
  7. Find R961 Slitting Production Summary Report.
  8. Select the period, export as CSV and name the file Slitting.
  9. Now go to 06.410.03 – Production Engine (Process Wise) module & open it.
  10. Find R950 Final Cutting Scrap Report-PBI on the right side.
  11. Select the period, export as CSV and name the file Final_Cutting.
  12. Now go to 06.300.00 – Special Engines – Sales & Distribution and find Seamless Scrap Report. Find R984 – Seamless Scrap Qty, export as CSV and name the file M2M.
  13. Open the Scrap_MIS_Dashboard_Generator.html file and upload Welded, Seamless, Slitting, Final_Cutting and M2M. Your dashboard is ready.
